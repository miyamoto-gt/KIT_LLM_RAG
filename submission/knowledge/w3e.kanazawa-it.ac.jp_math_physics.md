# 物理ナビゲーションについて
KIT物理ナビゲーションは，高校と大学1,2年で学習する内容を中心とした物理のeラーニング教材です．1ページ１知識のコンセプトで，どのページからでも学習でき，物理の辞書のように利用していただくと便利です．本サイトは，「第11回 日本e-Learning大賞」ニューテクノロジー賞を受賞したKIT数学ナビゲーションの物理版として作成されており，そのコンセプトを受け継いでいます．現在，数理工統合教育を実現するKIT STEMナビゲーションのコンテンツの1つとして位置づけられています．
今後，さらに内容を充実させていきます．（作成スタッフ）
本サイトのコンテンツは，高校・大学などの教育機関において，許諾を得る必要なく配信・複製・改変など自由にご利用できます．詳しくは，利用規約をお読みください．
# 特徴
1. ### 高校から大学の知識へ，スムーズな橋渡し 高校の知識から大学の知識へ，よりスムーズな高大接続の学習を促進します．また，高専と大学のスムーズな橋渡しを促進します．
2. 物理の基礎をなす数学とハイパーリンクでつなぎ，断片的な知識を関連付けて理解することで，論理的に考える能力が徐々に身につきます．本サイトで出てくる数学的な内容については数学ナビゲーションにハイパーリンクしています．
3. ### 動画コンテンツによる理解の促進 動画を見てから法則を理解することで，動的な現象をどのような法則で表現するか，理解を深めることができます．また，シミュレーション教材で法則を表現する手法を学ぶことができます．
4. ### リンク・バック・ラーニング KIT数学ナビゲーションと同様にハイパーリンクをたどりながら基礎に向かって学習でき，積み重ねの学習がなくても，ピンポイントに知りたいことの理解を，ハイパーリンクを活用して深めることができる環境を提供します．
5. ### ICT教材として活用 1ページ１知識のコンセプトで作成しているため，インターネットが接続できる環境で，高校や大学の授業でもICT教材として活用できます．シミュレーションも活用しながら物理法則を簡潔に説明するためのICT教材を活用することで，アクティブラーニングを効果的に実践し，その時間を確保するためにも活用して下さい．
# 知識構造の可視化
物理ナビゲーションは，STEMナビゲーションのコンテンツの1つで、STEMナビゲーションには他に数学ナビゲーションと工学ナビゲーションがあります．知識を記載した各ページはハイパーリンクで関連付けられています．その様子を示したのが下の周辺知識グラフです．グラフの丸印は各ウェブページを示し，その下にページタイトルが示されています．丸印間の矢印はハイパーリンクを表わします。丸印をクリックするとページが開きます．
# 周辺知識グラフ
グラフの白枠で強調されているウェブページ（この場合は力のモーメント）を中心としたリンク3つ以内のウェブページを抽出した知識グラフです．
