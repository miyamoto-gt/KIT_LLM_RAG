【定積分の問題】
次の問題を積分せよ(定積分)．
∫ 1 2 ( x 3 − 3 x 2 + 1 x ) d x
− 21 4 + 2 2
定積分の基本式より
∫ a b f ( x ) d x = \[ F ( x ) \] a b = F ( b ) − F ( a ) ･･････(1)
基本となる関数の積分より
∫ x α d x = 1 α + 1 x α + 1 + C （ C は積分定数） ･･････(2)
を用いる．
∫ 1 2 ( x 3 − 3 x 2 + 1 x ) d x
（計算しやすいよう， 1 x = x − 1 2 （累乗）に変換）
= ∫ 1 2 x 3 d x − 3 ∫ 1 2 x 2 d x + ∫ 1 2 x − 1 2 d x
(定積分の基本式より，式を変形)
= \[ 1 3 + 1 x 3 + 1 \] 1 2 − 3 \[ 1 2 + 1 x 2 + 1 \] 1 2 + \[ 1 − 1 2 + 1 x − 1 2 + 1 \] 1 2
（ヒントの式(1)，(2)を適用する）
= \[ 1 4 x 4 \] 1 2 − 3 \[ 1 3 x 3 \] 1 2 + \[ 2 x 1 2 \] 1 2
= 1 4 ( 2 4 − 1 4 ) − ( 2 3 − 1 3 ) + 2 ( 2 1 2 − 1 1 2 )
= 16 − 1 4 − ( 8 − 1 ) + 2 ( 2 − 1 )
= − 21 4 + 2 2
