# 修了証明書発行
本専攻修了生（虎ノ門キャンパスにて修了された方）を対象に証明書を発行致します。個人情報を保護する観点から、各種証明書を発行する際、申請者の本人確認をさせていただきます。申請時に確認書類等の提示をお願いいたしますので、ご理解、ご協力のほどよろしくお願いいたします。
※金沢本校にて修了された方のお取り扱いはしておりません。金沢本校の卒業生は下記をご確認ください。
金沢本校の卒業生 各種証明書の発行について
| 証明書の種類 | 手数料（1通） |
|---|---|
| 修了証明書 | 1,100円 |
| 在籍期間証明書 | 1,100円 |
| 成績・単位修得証明書 | 1,100円 |
| 成績通知書 | 1,100円 |
| その他証明書 | 1,100円 |
| 英文各種証明書 | 2,100円 |
## お申し込み方法
各申請用紙、お申込み手順のご案内がご覧頂けます。
*※本専攻修了者のみ、虎ノ門キャンパス窓口での現金取り扱いが可能です。 尚、金沢本校の卒業生の証明書のお取り扱いはしておりませんのでご注意ください。*
## 証明書の発行について
【窓口でお渡し】　即日発行を希望される場合は事前にお知らせください
【翌日発送】　FAX・郵送からのお申込みの場合
【3日～1週間程度】　特殊証明書、英文証明書の場合
◎修了年度によっては、即日お渡しできない場合がございます。
◎返信用封筒・郵送料は本学で用意致します。
◎県外の方は全て速達発送です。
※月曜/祝日 定休となりますので、ご注意ください。
