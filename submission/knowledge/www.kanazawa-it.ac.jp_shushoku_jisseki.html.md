## 学部卒業生 就職実績
### 2026年3月卒業生の就職実績
| 卒業者 | 1,436名 |
|---|---|
| 進学者 | 262名 |
| 就職希望者 | 1,145名 |
| 就職内定者 | 1,144名 |
| 自 営 | 1名 |
| 自力開拓 | 28名 |
| 就職内定率 | 99.9％ |
※2026年3月31日現在のデータです。
※就職内定率99.9%は文部科学省「大学等卒業者の就職状況調査」の計算方法で算出したものです
計算方法：就職内定率＝就職内定者数／就職希望者数×100
※（就職内定者数+自営）÷（卒業者－大学院進学者数）×100でも、KITは97.3%という高い就職率になります
※KITでは、大手企業を資本金3億円以上、もしくは従業員300名以上の企業としており、全企業のうち約1%の企業がその条件に該当します
※「自力開拓者」とは、次年度も公務員試験を目指すなど、自力での進路開拓を希望する者のことです
