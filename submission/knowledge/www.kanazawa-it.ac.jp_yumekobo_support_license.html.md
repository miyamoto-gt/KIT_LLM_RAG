| ものづくりの際に必要となる基本的な安全作業と手工具・加工機械の使い方を習得することで安全な作業を行うための意識付け、加工方法の向上を目指します。 **※変更点** 2023年4月よりSTEP1「 **安全講習**」とSTEP2「**木材加工**」、「**電気・電子**」**、**「**板金**」、**「ボール盤**」、「**フライス盤**」、「**旋盤**」は、事前講習を受講後、夢考房で実習を行う“ベストマッチ方式”で実施します。 右側のボタンの事前講習を受講し、受講証明書を **印刷**し**実習時に持参して下さい。** |  |

| STEP1 安全講習 |
| 安全と応急処置の考え方、手工具を中心とした工作実習と夢考房の機器・設備について紹介を行います。簡単な金属加工・木材加工を体験しながら安全に作業を行う心構えを身につけます。 ※実習時に事前学習受講証明書が必要になります。 |
| STEP2 |
| 安全講習修了者が受講できます。機器・装置の安全な操作方法、加工方法および計測方法が習得できます。自分の目的に合わせて希望のコースを受講してください。6コースあります。 |
| 木材加工 | 危険度の高い木工機械の取り扱いを習得する。（パネルソー、丸のこ盤、糸のこ盤、横切盤等） |
| 電気・電子 | はんだ付け、配線の接続、サーキットテスター・安定化電源の使い方を習得する。 |
| 板 金 | メータパネルを製作することで板金の基礎を習得する。 （シャーリング、プレスブレーキ、コンターマシン等） |
| ボール盤 | ボール盤による金属の穴開け加工と計測機器の取り扱いを習得する。 (大型・小型ボール盤、ノギス、マイクロメータ、ハイトゲージ等) |
| フライス盤 | 平面・溝等を加工する機械。 （正面フライス、エンドミルによる加工を行う） |
| 旋 盤 | 丸い物を削る機械。（外径削り、端面削り、Ｃ面削り、溝入れ等） ※実習時に事前学習受講証明書が必要になります。 |
| STEP3 |
| 「金属加工」「電気」講習のさらに上級技能を習得するために4コースを開講しています。希望のコースを選択して受講してください。 |
| **電気コース受講済みのみ対象者** |
| プリント基板 | 基板加工機の使用方法を習得する。(各自ノートバソコンを持参して下さい) |
| 回路設計 | アナログ回路設計・デジタル回路設計の実践、計測器の使用方法説明。 |
| **板金コース受講済みのみ対象者** |
| 溶 接 | 鉄−鉄、アルミーアルミ を継ぎ合わせる（CO <sub>2</sub>溶接、TIG溶接） |
| **ボール盤・フライス盤・旋盤の3コース受講済みのみ対象者** |
| ＮＣフライス盤 | コンピュータ制御で加工を行うフライス盤による金属加工を習得する。 |
| 開講場所・スケジュール |
| 受付 |
| ■ | 予約は、開講日の4日前の午前8時から開始します。 |
| ■ | 予約時は、希望する講習日を選択し、「学籍番号」「パスワード」を登録してください。 |
| ■ | 2日前の午前7時45分の時点で、定員を超えた場合は抽選となります。抽選結果はホームページにて確認してください。 |
| ■ | 定員に満たない場合は、開講当日の15分前まで先着順で予約を受け付けます。 |
| ■ | 予約は、1日に1項目となります。 |
|  |
| キャンセル |
| ■ | 開講当日の30分前までに夢考房のホームページからキャンセル手続きを行ってください。この手続きには、予約時に設定したパスワードが必要です。 |
| ■ | 予約時にパスワードを設定しなかった場合、パスワードを忘れた場合は、夢考房に申し出てください。 |
| ■ | 無断欠席された場合は、ペナルティとして、以降30日間は予約、受講できません。すでに予約済みの分はキャンセルされます。 |

| 服装 |
| ●「実験着」など、講習が受講できるような上下の服装、「保護めがね」等を準備ください。 ●肌の露出の多いTシャツや半ズボン、サンダル、かかとを踏んだズック等の履物やブーツなどのかかとの高い履物では受講できません。 ●ズボンはきっちりと腰でベルト留めし、ずり落ちたりしないようにしてください。 ●ベルトに付いているキーホルダーやアクセサリーなどのぶらつくものは、機械に巻き込まれる危険があるので禁止です。 |
